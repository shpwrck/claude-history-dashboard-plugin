# Experiment runtime contract boundary

`contracts/v1` owns the harness-neutral wire contract for three authoritative
documents: immutable versioned Definitions, immutable terminal Runs, and the
replaceable current Verdict for a trial. The sibling `schemas/v1` files are the
published Draft 2020-12 assets. The codecs apply strict JSON preflight, those
schemas, canonical digests, immutable registry semantics, and referential
context in that order.

The boundary deliberately contains no adapter, store, selector, state machine,
dashboard parser, harness home, vendor CLI, or legacy-ledger migration. In
particular, adding this module does not enroll a session or change the current
experiment harness. Runtime and adapter integration belong to later slices of
epic #2582.

## Digest rules

- Documents use RFC 8785 canonical JSON after sorting only arrays whose order
  the v1 contract declares irrelevant. `contentDigest` itself is omitted.
- A Behavior Fingerprint hashes the complete manifest with only its own
  `digest` omitted, per #2609. `observedAt` and optional `displayValue` remain
  audit-bearing bytes; only factor order is normalized.
- Extension-owned arrays retain order. The contract never guesses that an
  extension's list is a set.
- Inputs outside the strict JSON domain (including negative zero, non-finite
  numbers, unsafe integers, lone surrogates, sparse arrays, and cycles) fail
  before schema validation.

## External resolution

Definitions resolve exact semantics, selector, operation, fingerprint-policy,
and Verdict-policy registrations. Runs additionally resolve the minimal
immutable Selection Receipt binding from #2610 and any exact per-Run operator
safeguard authority. Receipts and mutable reservation state are not copied into
the authoritative document trio. Downstream Run and Verdict contexts accept
only opaque, frozen values returned by the preceding codec; a record loaded
from JSON must be decoded again before it can authorize retry lineage, Verdict
evidence, or a Verdict correction. Verdicts resolve exact Run ID/digest pairs;
cross-harness applicability remains a rebuildable read model rather than
authoritative Verdict state.

The checked-in corpus under `fixtures/experiment-runtime/v1` is deterministic,
offline, and generated by `scripts/generate-experiment-contract-fixtures.mjs`.
