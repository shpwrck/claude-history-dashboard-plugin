# v0.5.0 security sweep (2026-06-24)

Full application security review feeding the v0.5.0 security gate (epic **#1476**). A deep
multi-agent pass audited the six distinct security surfaces of the dashboard + operator
substrate. Every finding below was **verified against `origin/master`** (the local working
tree was 21 commits behind at audit time) so already-fixed code is not reported as a gap.

This is the "fresh `/security-review` pass" the #1476 gate body calls for. Dashboard findings
are filed as children of #1476 (milestone v0.5.0); operator findings are filed under the
operator hardening epic **#1716** (milestone Future) because the operator is paused
(replicas=0) and is not part of the v0.5.0 shippable surface.

## Scope (surfaces audited)

1. HTTP API authentication / authorization / CSRF (`scripts/server.mjs`)
2. Filesystem write-back, path traversal, untrusted-input file I/O (`scripts/server.mjs`, `src/lib/*`)
3. LLM egress governance & secrets handling (`src/lib/anthropic-egress.ts`, `llm-registry.ts`, `claude-api.ts`, ADR 0008)
4. SPA/server split boundary & client-side web vulns (XSS / CSP)
5. Kubernetes operator (`probaitio-operator/`, ADR 0010/0011)
6. Container images, reverse proxy / TLS, secrets-in-repo, dependency supply chain

## Findings detail

### F1 — CRITICAL — raw `~/.claude` transcript content egresses unredacted (egress)

`egressScrub()` (`src/lib/anthropic-egress.ts:220-253`) is a pure identity pass-through: it
computes a byte length, logs a receipt, and returns `content` byte-for-byte unchanged
(`anthropic-egress.test.ts:105-119` asserts `result.content === content` over the literal
`'secret prompt text'`). No `redact`/`sanitize`/`local-model` implementation exists anywhere
in the egress path.

The `server.audit-judge` deceit path (`scripts/server.mjs:7949-8002`) decompresses the real
`session_transcript` brotli blob from `~/.claude` and renders raw assistant prose (`CLAIM:`)
and raw tool inputs (`ACTION: <name> <input>` — command-line args, file paths, env values,
pasted secrets, emails, API keys) into a ~12 KB prompt that flows through the identity stub
and out via `callAnthropicMessages('server.audit-judge', …)` to api.anthropic.com.

**Why CRITICAL, not deferred to public exposure:** the leak is live the moment the documented
opt-in is set (`DASHBOARD_ENABLE_SERVER_LLM_AUDITS=1` + `ANTHROPIC_API_KEY`).
`validateLlmPrePublicExposure` only blocks `publiclyReachable: true` while scrub is `'stub'`,
and Phase-1 defaults are `publiclyReachable: false` — so a single-tenant operator gets
unredacted egress today with no gate firing. The ADR 0008 content-protection invariant is
satisfied only ceremonially. The CI gate `check-llm-egress.mjs:165-169` cannot catch it — it
only checks that an `egressScrub` call-site *exists*, not that it redacts.

**Fix:** implement a real local redaction step (token/API-key/path/email/env) and switch the
registry entry to `egressScrub: 'local-model'`; until then the audit-judge path must not be
enabled-by-default and the registry/docs must stop claiming "scrubbed." Add a test asserting a
known secret in a transcript ACTION line does not appear in the egress payload.

### F2 — HIGH — no egress NetworkPolicy on session pods (operator)

Session pods (`pod.go:94-110`) run arbitrary phone-driven `claude remote-control
--permission-mode auto` sessions with the OAuth credential mounted read-only, on a cloned
arbitrary repo. ADR 0010 (lines 55/59/87) states egress should be "pinned to the model
endpoint only" via NetworkPolicy/Cilium, but `config/network-policy/` contains only
`allow-metrics-traffic.yaml` (metrics ingress). No `policyTypes: [Egress]` policy selects the
session pods, so a poisoned repo can read `/workspace/.claude/.credentials.json` and POST it
anywhere. The promised jail does not exist. **Fix:** ship a default-deny egress NetworkPolicy
allowing only kube API, DNS, ingest, and the model/control endpoints.

### F3 — HIGH — ingest bearer token in plaintext pod-spec env (operator)

`pod.go:146` injects `{Name: "PROBAITIO_INGEST_TOKEN", Value: r.IngestToken}` as a literal env
value — stored plaintext in the pod object, readable via `kubectl get pod -o yaml` by anyone
with `pods get` (which the dispatch SA holds namespace-wide). The dashboard path does this
correctly via `SecretKeyRef` (`dashboardinstance_controller.go:135-137`). **Fix:** inject via
`SecretKeyRef` to the existing `probaitio-ingest` Secret.

### F4 — HIGH — registry cites a non-existent symbol (egress auditability)

`src/lib/llm-registry.ts:149` maps `browser.ask-claude` → `symbol: 'callClaude'`, but
`claude-api.ts:162` exports `chat`. `validateLlmUsageRegistry` only checks the symbol string is
non-empty (`:206-207`), never that it resolves, so the governance manifest points auditors at a
symbol that does not exist. No live leak. **Fix:** set `symbol: 'chat'` and add a test asserting
each server `callSite.symbol` resolves in its `callSite.file`.

### F5 — MEDIUM — enterprise-auth behavior suite not in CI (auth)

`npm test` globs `src/**/*.test.{ts,tsx}`, which never matches `scripts/enterprise-auth.test.mjs`,
and no workflow runs `npm run test:enterprise-auth`. CI runs only the static
`test:enterprise-route-inventory` / `gate:enterprise-posture` gates, so a regression in
`passesWriteAuth` / `isSameOrigin` / `jwtSignatureValid` / cookie-crypto ships CI-green. **Fix:**
add a required CI step running the behavior suite; fix its ENOENT cache-dir crash in the same
change.

### F6 — MEDIUM — `/api/policy/write` integrity/DoS (write-back)

The only route that mutates the user's live global `~/.claude/settings.json` has three gaps in
`src/lib/policy-writer.ts`: (1) non-atomic `writeFile` (`:174`) — a crash mid-write corrupts
the live config, and concurrent writes race; (2) unbounded timestamped backups (`:159-162`) —
a same-origin write loop sprays thousands of `settings.json.backup-*` files (disk-fill DoS of
`~/.claude`); (3) rule strings unvalidated (`:44-48`) — any string lands verbatim in
`permissions.{allow,deny,ask}`, allowing injection of over-broad `Bash(*)` allow rules. **Fix:**
temp-file + atomic `rename` with a write mutex; prune backups; validate rules against the
`Tool(pattern)` grammar.

### F7 — MEDIUM — static SPA ships no security headers (SPA)

The server build sets a full CSP + HSTS + XFO + nosniff suite (`scripts/server.mjs:671-683`);
the static SPA inherits none of it — `nginx.spa.conf.template` adds only `Cache-Control`,
`index.html` has no meta-CSP, and there is no `public/_headers` for the GitHub Pages
deployments hosting the public SPA. The SPA also persists the Ask-Claude API key in
`localStorage` (`src/lib/claude-api.ts:41`), readable by any origin script (the auth token
correctly uses `sessionStorage`). XSS is otherwise well-defended, so this is defense-in-depth.
**Fix:** add `public/_headers` + nginx `add_header` mirroring the server CSP with `connect-src
'self' https://api.anthropic.com`; move the API key to `sessionStorage`.

### F8 — LOW — server fails open beyond loopback without credentials (container)

`isAuthorized()` returns `true` when `DASHBOARD_USER`/`PASS` are unset (`scripts/server.mjs:3792-3804`).
Safe at the default loopback bind, but an operator who sets `BIND_HOST=0.0.0.0` without
credentials exposes the full `~/.claude`-reading server unauthenticated on the LAN, guarded only
by a code comment. **Fix:** warn loudly or fail closed on a non-loopback bind with no auth mode
unless an explicit `DASHBOARD_ALLOW_INSECURE_BIND=1` override is set.

### F9 — LOW — operator multi-tenant hardening gaps (operator)

Folded into #1716's existing tracks: namespace-wide `pods get;patch` on the dispatch SA
(`dispatch_role.yaml:21-23`, already flagged as an MVP compromise and the read primitive behind
F3); `--permission-mode auto` with no `readOnlyRootFilesystem` (`pod.go:31,37-44`); CRD-supplied
`REPO`/`REF` unvalidated in the operator (`pod.go:187-193`, git argument-injection vector, host
allowlist enforced only outside the operator); no admission/validating webhook enforcing ADR
0010's "policy is a ceiling settings.json may only narrow."

### F10 — LOW — file-I/O defense-in-depth (write-back / file I/O)

Three latent smells on otherwise-contained paths (all reads are guarded by
`normalize`+`pathInside`+`realpath`+`.jsonl` suffix, empirically confirmed to reject every
traversal payload): redundant double `decodeURIComponent` (`server.mjs:7013` then `:8095/:8123/:8132-8133`)
that re-expands `%252e%252e%252f` to `../`; symlink-blind push-ingest write
(`:3739-3751` uses `normalize`, not `realpath`; token-gated, default-off); and
`AnthropicEgressHttpError` retaining the full upstream body (`anthropic-egress.ts:80-90`, not
logged today but one handler-change from a leak). **Fix:** decode once; realpath/`O_NOFOLLOW`
the ingest write; truncate/scrub the retained error body.

### F11 — LOW — third-party GitHub Actions on mutable tags (supply chain)

`docker/metadata-action@v6`, `docker/login-action@v4`, `peaceiris/actions-gh-pages@v4` are
pinned to mutable major tags in a `packages: write` / Pages-deploy context. Mitigated by narrow
permissions and no PR-head exposure. **Fix:** pin to full commit SHAs (+ optional Dependabot
`github-actions`).

## Verified solid (no action required)

- **Dependencies:** `npm audit --omit=dev` reports 0 production vulnerabilities; the 2 dev-only
  advisories never ship in the zero-`node_modules` runtime image (ADR 0007).
- **Secrets in repo:** none. The `*.ts.net.crt` at the root is a public Let's Encrypt cert chain
  (no paired key), untracked and `.gitignore`d.
- **XSS:** transcript content renders as JSX children (React auto-escaping); zero
  `dangerouslySetInnerHTML` / `innerHTML` / `eval` in source; the hand-rolled Markdown renderer
  emits no link/URI sink.
- **SPA/server boundary:** airtight — stub client + Vite alias + the `spa-boundary` CI grep;
  no server secrets or `~/.claude` content reach the static bundle.
- **Path traversal (reads):** every request-driven file read is contained by
  `realpath`+`pathInside` with a `.jsonl` suffix gate; all `../`/percent-encoded/double-encoded
  payloads rejected.
- **Auth:** route allowlist is default-closed; JWT pinned to `RS256` with exact-kid match (no
  alg-confusion); session cookie is correct AES-256-GCM with random IV + AAD + auth-tag + epoch
  revocation + decrypt-only rotation key; all mutating routes gated by same-origin + CSRF token.
  The v0.3 `/api/insights/regenerate` CSRF hole (#1005) stays closed — the route was removed.
- **Decompression:** every `brotliDecompressSync` / `gunzipSync` site passes `maxOutputLength`;
  no uncapped inflate / zip-bomb path.
- **Containers:** runtime runs `USER node`, zero node_modules, `~/.claude` mounted `:ro`,
  `read_only` + `cap_drop: ALL` + `no-new-privileges`, host port loopback-bound by default,
  curl-free Node healthcheck. `pull_request_target` workflow checks out base ref only (no
  PR-head execution); no `run:`-body interpolation of `github.event.*`.

## Method

Six specialized adversarial reviewers ran in parallel (one per surface), each instructed to
construct concrete exploit scenarios, cite `file:line`, and verify each finding still exists on
`origin/master` before reporting it. Results were synthesized, de-duplicated against the three
already-banked concerns (#1578/#1579/#1581), and decomposed into the issues tracked above.
